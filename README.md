Retail Sales SQL Analysis – Beginner Project

Project Background
As I am entering the Data Analytics field, I started learning Excel first and then moved to SQL as the next step in my learning journey.
After practicing SQL fundamentals for 3–4 days, I built this project independently using a synthetic practice dataset to strengthen my understanding of database design and SQL queries.

Database Design
In this project, I:

Created a database schema for retail sales analysis

Designed three tables:
  -Customers
  -Products
  -Orders

Inserted structured data into all tables

The tables are connected using customer ID and product ID to perform relational analysis.

SQL Concepts Used
 -CREATE TABLE
 -INSERT INTO
 -INNER JOIN
 -GROUP BY
 -ORDER BY
 -Aggregate Functions (COUNT, SUM, AVG)
 -Revenue calculation using expressions (price × quantity)


Analysis Performed

 -Joined customers, products, and orders tables to retrieve customer purchase details.
 -Calculated total number of orders per customer using GROUP BY.
 -Calculated total quantity of products sold.
 -Found the average price of products.
 -Calculated total sales revenue by multiplying product price with quantity sold.


Key Learning
Initially, I struggled with understanding JOIN operations and how tables connect. Through practice, I understood how relational databases work and how SQL can generate meaningful outputs from structured data.
This project represents my first practical step into SQL-based data analysis.

Note
This project uses a synthetic dataset created for practice and learning purposes.
